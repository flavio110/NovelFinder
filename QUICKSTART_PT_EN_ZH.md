# NovelFinder 1.0.1 Stable — Quick Start

## Português

1. Baixe `NovelFinder_1.0.1_STABLE_PUBLIC_RUNTIME.zip` na página da release.
2. Confira o SHA-256: `C7B47DDC3515D63BDC012DFA43FD3C91078623AA139FC62332BEA46498BB4FCC`.
3. Extraia o ZIP.
4. Execute `INSTALAR_NOVELFINDER_1.0.1_STABLE.cmd`.
5. Após a instalação, abra `C:\NovelFinder\ABRIR_NOVELFINDER.cmd`.
6. Configure APIs, modelos locais e integrações opcionais somente depois que a base estiver funcionando.

Requisito principal: Python 3.11. A instalação de dependências pode usar internet. O pacote público não inclui credenciais do desenvolvedor.
