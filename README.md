## Installation

1. Download the Stable ZIP.
2. Extract it.
3. Run `INSTALAR_NOVELFINDER_1.0.1_STABLE.cmd`.
4. After installation, open `C:\NovelFinder\ABRIR_NOVELFINDER.cmd`.

Python 3.11 is required. The installer can use the internet to install Python
dependencies. API credentials and local AI models are not included.
