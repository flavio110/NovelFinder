## 🇧🇷 Português

O **NovelFinder** é um aplicativo para Windows voltado a pesquisa de novels e automação de fluxos multilíngues. A linha do projeto é **Native First, External Assist**: priorizar ferramentas locais/próprias e usar serviços externos apenas como aceleração ou recurso complementar quando disponíveis.

### O que a versão 1.0.1 entrega

- pesquisa e apoio à identificação de novels;
- fluxos de tradução e processamento multilíngue;
- base para áudio, dublagem, OCR/visão e processamento de mídia;
- integração com recursos locais e provedores externos opcionais;
- execução local-first, sem incluir credenciais do desenvolvedor no pacote público;
- proteção contra gasto automático com provedores pagos.

### Instalação rápida

1. Baixe o ZIP da versão Stable.
2. Extraia o arquivo.
3. Execute `INSTALAR_NOVELFINDER_1.0.1_STABLE.cmd`.
4. Depois da instalação, abra `C:\NovelFinder\ABRIR_NOVELFINDER.cmd`.

**Requisito:** Python 3.11. A instalação de dependências pode usar internet. APIs, modelos locais e integrações opcionais são configurados separadamente.
